# DAPI TEAM — сайт

Быстро. Стильно. Безопасно.

## Структура

```
index.html              — Главная (готова)
assets/css/style.css     — стили (светлая тема, палитра небо/хвоя/песок/туман)
assets/js/main.js        — экран загрузки, мобильное меню
assets/fonts/            — Berier Regular/ExtraBold (доработанная копия — см. ниже)
assets/images/           — лого-знак (svg), хиро/экран загрузки (jpg)
```

Остальные страницы (services.html, cases.html, about.html, process.html,
events.html, media.html, contact.html) в навигации указаны, но ещё не
свёрстаны — это первый шаблон, дальше добавляем страницу за страницей.

## Шрифт Berier — важно

Файл шрифта — бесплатная раздача с befonts.com (на деле это шрифт **Al Markha
Type**, almarkhatype.com, просто переименованный). Лицензия — «Free for
Personal Use», для боевого сайта **нужно купить лицензию у Al Markha Type**
до реального запуска.

Цифра «2» в исходном файле была намеренно испорчена (заменена на рекламный
водяной знак) — она перерисована вручную и вклеена в шрифт. Символ «/» и «!»
всё ещё битые (тоже показывают водяной знак) — в текстах на Berier их пока
избегаем.

## Локальный просмотр

```
python -m http.server 8000
```

и открыть `http://localhost:8000/`.
